# 2020 Legacy: What Is Kept, Retired or Replaced

This record traces every element of the 2020 design that the case statement mentions to a single decision for the 2026 update: Keep, Retire or Replace. It does not design any replacement. Where a replacement is needed, the row names the later task that designs it. It meets challenge point 1 (Gobierno): "Registro de qué requisito de 2020 se conserva y qué componente se retira" (a record of which 2020 requirement is kept and which component is retired), which "Va en el documento de arquitectura" (goes in the architecture document)

[`docs/case/case-statement.pdf`](case/case-statement.pdf) is the only source of requirements, and the only source used here for what the 2020 design contained (ASM-040). The case statement frames the update in one sentence: "Se conserva el requisito que siga vigente y se reemplaza el supuesto de conectividad" (the requirement that is still valid is kept, and the connectivity assumption is replaced). Quotations are in the original Spanish, which prevails over the English rendering (ASM-001).

## Decision values

| Decision | Meaning in this record |
|---|---|
| Keep | The 2020 requirement stays in force in 2026 as the case statement states it. |
| Retire | The 2020 element is dropped and nothing in the 2026 design takes its place. |
| Replace | The 2020 element is dropped and the case statement requires a 2026 element in its place, which the named task designs. |

## Exclusion of 2020 quotes, prices, devices and cloud services

The case statement states that "Precios, dispositivos y servicios de nube de 2020 no son cotización válida" (2020 prices, devices and cloud services are not a valid quote). The case statement does not name any 2020 price, device model or cloud service, and this record names none. Rows L-14 to L-16 retire them as a class. No 2020 figure is used anywhere in this repository; costs are priced at current prices by A23 ([roadmap#36](https://github.com/aroma-pacifico/aroma-pacifico-roadmap/issues/36)) under PD-017, and the cloud is chosen in [`docs/adr/adr-001-primary-and-second-cloud.md`](adr/adr-001-primary-and-second-cloud.md).
